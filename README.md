### 02. AquaGuard AI
**AI-Powered Fish Disease Screening and Aquaculture Monitoring**

AquaGuard AI is an ongoing Flutter application project exploring how mobile machine learning can support fish farmers in Bangladesh.

**Key Features**

- Two-stage fish image screening workflow.
- Fish-versus-non-fish image verification.
- Seven-class fish image classification using EfficientNetB0.
- TensorFlow Lite integration for on-device inference.
- Water-quality assessment using recorded pond readings.
- Aquaculture guidance and pond record management.
- Bangla aquaculture assistant with voice interaction.
- Local functionality with cloud synchronization when available.

**Model Development**

| Component | Details |
|---|---|
| Disease classifier | EfficientNetB0 |
| Classification categories | 7 |
| Disease-classification dataset | 5,257 images |
| Reported test accuracy | 98.70% |
| Fish verification dataset | 12,090 images |
| Reported verification accuracy | 99.83% |
| Model input | 224 × 224 RGB |
| Mobile integration | TensorFlow Lite |

**Technology Stack**

`Flutter` `Dart` `Python` `TensorFlow` `TensorFlow Lite` `Computer Vision` `Firebase`

*These figures represent reported model evaluation results, not verified real-world diagnostic performance. Further field testing is required.*
